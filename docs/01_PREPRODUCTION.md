# made by f4r3n9e1t — Pre-production

Три принципиально разные концепции → сравнение → выбор → зафиксированный art direction.
Документ написан до кода; всё, что реализовано, следует разделу «Locked art direction».

---

## Concept A — RENDER REGION

**1. Идея.** Сайт как вьюпорт Blender в момент рендера. Мир изначально существует только как
топология — сетка, wireframe, «идея». Посетитель курсором «выделяет регион рендера» (как Ctrl+B
в Blender), и внутри него геометрия становится материей: свет, материал, тень. Метафора бренда:
*Turning imagination into geometry* — буквально, на экране.

**2. Атмосфера.** Тёмная студия ночью. Один ключевой свет, контровой красный, пустота вокруг.
Технический, но не «sci-fi»: всё, что похоже на интерфейс, — настоящие термины пайплайна
(wireframe, clay, shaded), а не выдуманные readouts.

**3. Палитра.** Void `#070707`, graphite `#111113` / `#1a1a1d`, line `#2a2a2e`, cold grey `#6c7076`,
fog `#a7abb1`, bone `#e7e3da`, blood `#c3141e` (регион рендера, активные состояния), neon
`#ff3b3b → #ffd1d1` — только неоновая подпись «made by f4r3n9e1t».

**4. Типографика.** Archivo Variable (ось ширины 62–125): ультра-узкий для гигантских заголовков,
широкий — для акцентов; ширина реагирует на курсор. IBM Plex Mono — подписи и метаданные.
Instrument Serif Italic — редкие поэтичные фразы-манифесты.

**5. Первый экран.** Гигантский `f4r3n9e1t` во всю ширину, за ним — WebGL-скульптура (расколотый
камень-«семя» с красным швом). Вне региона она видна как сетка, внутри — отрендерена. Курсор =
красная пунктирная рамка региона. Скролл раздвигает половины камня и расширяет регион на весь
экран — «рендер завершён».

**6. Галерея.** «Render queue»: закреплённая горизонтальная лента кадров разных пропорций
(2.39:1, 4:5, 1:1), каждый кадр проявляется «бакетами» — плитками в порядке спирали от центра,
как в Cycles. Второй режим — Index: типографский список с превью, следующим за курсором.

**7. Анимация.** Bucket-reveal изображений, tile-wipe переходы между страницами, переменная
ширина шрифта, магнитные кнопки, курсор, меняющий роль (регион / «Open» / стрелка).

**8. 3D / WebGL.** Одна лёгкая процедурная сцена Three.js (≈1 300 граней на десктопе,
≈500 на мобильных; фасетный камень читается лучше плотной сетки), шейдерный discard по региону, без постпроцессинга. Секретная страница-вьюпорт
с режимами шейдинга 1–4.

**9. Сильные / слабые.** + метафора идёт из ремесла автора, каждый эффект объясним; + узнаётся
мгновенно. − риск «интерфейса ради интерфейса» → лечится строгим правилом «только реальные
термины и реальные числа».

**10. Сложность.** Средне-высокая: кастомный шейдер, система тайлов, pinned-скролл.

## Concept B — BLACK ROOM / MONOLITH

**1. Идея.** Портфолио как кинотеатр после закрытия. Один луч проектора в пустом зале; каждая
работа — «сеанс». Бренд — титр в финале фильма.

**2. Атмосфера.** Анаморфный кинематограф, леттербокс 2.39:1, пыль в луче, тишина.

**3. Палитра.** Чёрный `#000`, тёплый серый `#2b2826`, плёночный белый `#efe9dc`, глубокий
красный `#7a0c12` только как свет рампы/таблички EXIT.

**4. Типографика.** Высокий контрастный антиква-гротеск (Fraunces/Didone) + узкий моно для титров;
всё по центру, как в начальных титрах.

**5. Первый экран.** Чёрный монолит в объёмном луче, медленно вращается; надпись появляется
как вступительный титр, по буквам.

**6. Галерея.** Полноэкранные «сеансы» по одному проекту за экран, леттербокс-маска раскрывается
при скролле, титры проекта снизу как субтитры.

**7. Анимация.** Медленные, тяжёлые: fade-through-black, затвор, мерцание проектора.

**8. 3D / WebGL.** Объёмный свет (raymarch/god rays) — дорого на мобильных; монолит банален.

**9. Сильные / слабые.** + очень кинематографично, эффектно на 1920. − «монолит в луче» — частый
шаблон; медленный темп утомляет при просмотре 10+ работ; слабо связан с 3D-ремеслом.

**10. Сложность.** Средняя по коду, высокая по производительности (volumetrics).

## Concept C — SIGNAL / XEROX UNDERGROUND

**1. Идея.** Сайт как андеграундный зин, перепечатанный на ксероксе и показанный через
ЭЛТ-монитор. Неоновая вывеска «made by f4r3n9e1t» — главный герой.

**2. Атмосфера.** Подвальный клуб, помехи, скотч, рваная бумага, дождь за окном.

**3. Палитра.** Ксерокс-чёрный, бумажный `#d9d4c7`, токсичный красный `#ff1f1f`, неоновый розовый.

**4. Типографика.** Ломаный коллаж: grotesk + машинопись + рукописный маркер.

**5. Первый экран.** Неоновая вывеска мерцает в дожде, ЭЛТ-искажение, глитч при движении мыши.

**6. Галерея.** Коллажная стена: работы приклеены скотчем под разными углами.

**7. Анимация.** Глитчи, дрожание, scanlines, stop-motion 8 fps.

**8. 3D / WebGL.** Шейдер ЭЛТ/глитча на весь экран; 3D-работы теряются под эффектами.

**9. Сильные / слабые.** + яркий характер, связан с неоновой традицией подписи. − эффекты
перекрывают сами рендеры (для 3D-портфолио это главный провал); глитч-эстетика — одно из самых
затёртых «дешёвых футуризмов»; плохая читаемость.

**10. Сложность.** Средняя; глитч-шейдеры тяжелы на слабых телефонах.

## Выбор — Concept A, RENDER REGION

Это единственная концепция, где каждое взаимодействие выведено из работы самого автора: регион
рендера, wireframe → материал, бакеты Cycles, нод-граф инструментов, режимы шейдинга. B красивее
на одном скриншоте, но говорит о кино, а не о 3D. C громче, но прячет работы под эффектами.
Неоновая подпись из C не смешивается в A как стиль — она остаётся одним «реквизитом» сцены, как
в рендерах автора (традиция подписывать сцены неоновым «made by f4r3n9e1t»).

## Locked art direction

- **Правило правды.** Любое число на экране — реальное (количество проектов, прогресс загрузки,
  год из конфига). Любой технический термин — настоящий термин Blender/пайплайна. Ни одного
  декоративного «SYS_OK 0x3F».
- **Правило красного.** Красный = «то, что сейчас рендерится / активно»: регион, активный фильтр,
  фокус, hover-линия. Не фон и не градиенты.
- **Неон** — только подпись `made by f4r3n9e1t`. Ник набирается моноширинным шрифтом, чтобы
  4/3/9/1 читались однозначно; «made by» — Instrument Serif Italic.
- **Без скруглений.** Радиус 0 везде. Карточек нет — есть кадры (frames) с тонкой рамкой
  и crop-марками.
- **Сетка.** 12 колонок, поля `clamp(16px, 4vw, 64px)`, gutter `clamp(12px, 1.6vw, 24px)`.
  Вертикальный ритм на шаге 8px.

### Дизайн-система

| Токен | Значение |
|---|---|
| `--void` | `#070707` |
| `--graphite-1/2/3` | `#0e0e10` / `#151518` / `#1f1f23` |
| `--line` / `--line-strong` | `#26262b` / `#3a3a40` |
| `--steel` | `#6c7076` |
| `--fog` | `#a7abb1` |
| `--bone` | `#e7e3da` |
| `--blood` / `--blood-dim` | `#d0161f` / `#5c0a0e` |
| `--neon-core` / `--neon-glow` | `#ffe3e3` / `#ff2b2b` |

Типо-шкала (fluid): mega `clamp(4.5rem, 21vw, 22rem)` · h1 `clamp(3rem, 9vw, 9rem)` ·
h2 `clamp(2.25rem, 5.2vw, 5rem)` · h3 `clamp(1.375rem, 2vw, 2rem)` · body 1rem/1.6 ·
meta (mono) 0.75rem, tracking 0.06em, uppercase.

Motion: easing `cubic-bezier(.2,.7,0,1)` (out-expo-like) для появлений, `cubic-bezier(.7,0,.2,1)`
для вайпов; длительности 240 / 480 / 900 ms. Под `prefers-reduced-motion` — мгновенные состояния,
без Lenis, без вращения скульптуры.

### Архитектура

```
src/
  config/        site.config.ts (бренд, контакты, соцсети, инструменты, категории, проекты), types.ts
  app/           App.tsx, routes, layout
  pages/         Home, Project, Viewport (секретная), NotFound
  sections/      Hero, Work, About, Toolset, Contact
  components/    Cursor, Nav, BucketImage, TileTransition, NeonSignature, MagneticButton, ...
  three/         sculpture.ts (сцена), webgl.ts (детект/фолбэк)
  animations/    reveal (IntersectionObserver), bucket order, smooth scroll (Lenis)
  styles/        tokens.css, base.css, + CSS-модули по секциям
```

Стек: React 19 + TypeScript + Vite, React Router, Three.js (ленивый чанк), Lenis.
GSAP/Motion не нужны: все анимации — CSS + Web Animations + один rAF-цикл.
